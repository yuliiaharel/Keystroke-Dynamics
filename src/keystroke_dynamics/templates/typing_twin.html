A party game, not a toy demo: every real player's enrollment and every attempt against them is scored by this app's real backend (the same Argon2id accounts, Postgres-backed profiles, and scaled-Manhattan scoring described on How It Works), each under their own random, disposable account. The three simulated practice players are fake data generated in your browser and never touch the backend. See the privacy note at the bottom of the page.

Privacy

Each real player you add registers a random, anonymous account (a generated username and password, never shown to anyone and not reusable) the first time they type. Only which key is pressed and when leaves the browser -- never the characters typed. The server stores a running mean and variance per key/key-pair for that account, not raw keystrokes, exactly as described in the main app's own privacy notes. As play moves between players, this page silently signs in as whichever player's profile the next attempt needs to check -- the account being scored is always the one that's actually logged in, the same rule every other page on this site follows.

Selecting New party deletes every real player's typing profile. Their account records (a random username and a password hash, with no typing data left on them) are not deleted, since this app has no account-deletion endpoint -- see the repository if that matters to you.
