Typing Twin

A game, not a toy demo: enrollment and every attempt here are scored by this app's real backend (the same Argon2id accounts, Postgres-backed profiles, and scaled-Manhattan scoring described on How It Works) under a random, disposable account created just for this play session. See the privacy note at the bottom of the page for exactly what that means.

Privacy

Playing registers a random, anonymous account (a generated username and password, never shown to you and not reusable) and signs in with it, the same as any other account on this site. Only which key you press and when leaves your browser -- never the characters you type. The server stores a running mean and variance per key/key-pair for that account, not your raw keystrokes, exactly as described in the main app's own privacy notes. Selecting Start over deletes that typing profile immediately. The account record itself (just a random username and a password hash, with no typing data left on it) is not deleted, since this app has no account-deletion endpoint -- see the repository if that matters to you.
